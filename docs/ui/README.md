# UI documentation index

The UI docs cover two levels:
- **Back office** — the shared authenticated shell (layout + navigation), in [`back-office.md`](back-office.md).
- **Pages** — one file per user-facing page.

Page files follow the same shape: Purpose, Access rules, Layout/Content, States, Localization,
Accessibility, Wanted changes, Out of scope.
