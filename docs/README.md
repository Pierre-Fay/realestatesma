# Documentation's index

### Architecture
Inside architecture can be found a file describing the architecture and the stack of the application

### Data
Inside data can be found 2 files :
- realestatesma.ddl : a DDL file, extracted from a Relational Diagram made with Oracle Data Modeler, the naming of the tables and the data type and length can differ from the application's implementation
- business-rules.md : a business rule defining markdown file, where the most critical business rules are described

### Domain
Inside domain can be found 3 files : 
- activity-diagram.txt : contains a plantuml activity diagram describing how the lead management works
- sequence-diagram.txt : contains a plantuml sequence diagram describing how the property submission flow works with user and agent roles
- class-diagram.txt : contains a plantuml class diagram illustrating the whole application's class structure (to be added)

### Functional
Inside functional is a complete functional analysis file, with planning for agile tickets, with user stories, MoSCoW, and git branch naming

### Ui
Inside ui you can find textual descriptions of individual page's wireframes (to be implemented)
