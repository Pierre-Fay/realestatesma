# Demo photo sources

The demo listing photos in this folder come from [Unsplash](https://unsplash.com) and are used under
the [Unsplash License](https://unsplash.com/license) (free to use, no attribution required).

`PropertySeeder` copies these files into the public storage disk (`storage/app/public/properties/`)
at seed time. `cover-1.jpg` … `cover-6.jpg` map to the six demo listings in order;
`gallery-1.jpg` … `gallery-6.jpg` form a shared gallery pool reused across listings.
